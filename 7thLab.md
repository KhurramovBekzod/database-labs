## primary keys and its index the way the handouts
7th_lab.sql file creates a primary key in four ways, builds tables with single and composite primary keys, and shows auto-generated ids with SERIAL, BIGSERIAL and IDENTITY.
The errors at the end are intentional: they show that a primary key rejects duplicate and NULL values, and that a table can have only one primary key.
